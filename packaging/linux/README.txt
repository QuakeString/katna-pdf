Katna PDF for Linux
===================

A fast PDF reader, editor and signer in the Katna family.
https://github.com/QuakeString/katna-pdf

Install it for yourself:

    ./install.sh

or for everyone on this computer:

    sudo ./install.sh

Then open Katna PDF from your desktop's menu, or run `katna-pdf FILE.pdf`.
`katna-pdf-cli` is the command-line tool (`katna-pdf-cli --help`).

Take it out again with `./install.sh --uninstall`, run the way you
installed it.

Optional: speech-dispatcher or espeak-ng for reading aloud; opensc and
pcscd for signing with USB tokens; your desktop's xdg-desktop-portal for
its own open and save dialogs.
